Privacy Policy

1. Overview & 100% Local Processing

CoreGrit Studio ("we", "our", or "us") developed Ai File Recovery (Package: com.coregritstudio.aifilerecovery) as a standalone, on-device utility application. We recognize that your photos, videos, audio recordings, documents, and personal contacts are profoundly private.

🛡️ Zero Data Transmission Policy: All scan engines, recovery algorithms, cache analyzers, and file restorations run 100% locally on your smartphone. We do not operate remote file storage servers, and we never collect, upload, transmit, sell, or inspect your personal files.
📁

2. Android System Permissions & Exact Usage

To provide core recovery and file management capabilities, the application requests specific Android runtime permissions. Each permission is used strictly for local device operations:

  • All Files Access (MANAGE_EXTERNAL_STORAGE / READ_EXTERNAL_STORAGE):
    Required exclusively to scan deep device directories, system cache partitions, hidden trash folders (.Trash), and unindexed storage sectors to discover lost or deleted photos, videos, audios, and documents, and to write restored files back to your device storage under /Download/Restored_Files/ upon your explicit request.
  • Granular Media Permissions (READ_MEDIA_IMAGES, READ_MEDIA_VIDEO, READ_MEDIA_AUDIO):
    Utilized on Android 13 (API 33) and newer devices to index and display recoverable media items for user selection and preview prior to restoration.
  • Contacts Access (READ_CONTACTS, WRITE_CONTACTS):
    Utilized solely when you intentionally trigger the "Contacts Recovery" module to scan for recoverable VCF backup files and re-import selected contacts directly into your local Android address book.
  • Notifications (POST_NOTIFICATIONS):
    Utilized on Android 13+ to send local device alerts when a long-running deep scan or batch file restoration completes.

6. User Control & Data Retention

You have full control over permissions and data at all times:

  • Permission Revocation: You can revoke storage or contacts permissions at any time via Android Settings > Apps > Ai File Recovery > Permissions.
  • File Management: Restored files are saved directly in your device's public /Download/Restored_Files/ directory and can be viewed, shared, or deleted at your discretion using any file manager.
  • Cache Purging: Uninstalling the application automatically deletes all temporary cache and scan indices generated by the app.
